# DayCoach Website

Landing page and Privacy Policy for the DayCoach iOS app, plus app-ads.txt for AdMob verification.

Files:
- index.html          — the landing page
- privacy-policy.html — privacy policy
- app-ads.txt         — AdMob authorised sellers file (must sit at the domain root)
- icon.png            — DayCoach app icon
- appstore.png        — Download on the App Store badge
- CNAME               — custom domain (www.mydaycoach.com)
